# Ready for Doom

A free, unofficial fan guide at [readyfordoom.com](https://readyfordoom.com). It tells the story leading to Avengers: Doomsday as 45 events, each with what caused it and what it leads to.

Plain HTML, CSS and JavaScript with no build step. To run it: `python3 -m http.server` in this folder.

- `data/story.json`: events, causes and Doom's moves
- `data/branches.json`: the main timeline and its branches
- `data/timeline.json`, `roster.json`, `theories.json`: films and series, cast, theories
- `js/config.js`: coffee link and contact form address
